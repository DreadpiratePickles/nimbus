2. **The scan database is a map of the estate.** The SQLite file holds every policy document, trust relationship, exposure and `risk.json` (0600); `nimbus.env` holds a live GitHub token (STATE.md line 4). No response proposes encryption at rest, a `purge`/retention command, a "what nimbus stores and for how long" page, or a test asserting that cloud credentials and secret values never persist. B puts eleven tracks in ten weeks, D six model tracks in six weeks, A eight Phase 0 tracks in three weeks.
