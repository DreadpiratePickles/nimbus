## Decisions (binding for plan v3)

1. **Phase 0 is not closed.** It closes when: verifier-2 defects are fixed (V2-iac done; V2-cli in flight) and **re-verified**; an **independently authored noise estate** (written by an agent that has not seen the engine's tuning) is added to the lab and precision is republished; `v0.2.0` is signed and installable; README claims match evidence. The **first live-cloud run** is item #1 of the whole programme and requires an owner action: lab AWS credentials (recorded as the top blocker, never hidden).
2. **Data model before wedge features (D's spine).** Weeks 1–6: typed inventory registry replacing substring `ClassFor`; permission-bearing edges (`can_perform{actions, statement}`) from a real policy evaluator; **path-level Issues** with stable ids `sha(kind|entry|anchor|rule)` so paths stop flapping and `verify` has an object; `resource_versions` history with per-resource diff; traversal scale (backward reachability pruning, explicit `Truncated` flag, 50k-node benchmark); **one rule engine** (migrate `rules.yaml` chains into attributed traversal rules).
3. **Effective IAM evaluator v1 in the first six weeks** (Deny, NotAction/NotResource, conditions → `unknown` not `allow`, permission boundaries, SCP/RCP, resource and KMS policies; ≥200-case corpus; cross-check against recorded `iam:SimulatePrincipalPolicy` fixtures). The plan-time path diff is **built in parallel on confidence-labelled paths** (`verified | inferred | hint`) and **launched publicly only after** evaluator v1, the noise estate and a live run (B/D order; not C's full-before, not A's after).
4. **Distribution plumbing now, launch gated.** Now: one name and one GitHub org (stop `nimbus`/`cloud-posture`/image-name drift), governance files (ADOPTERS, GOVERNANCE, MAINTAINERS, ROADMAP, OPEN_SOURCE_PROMISE, DCO), Action end-to-end on a pinned release, OCSF 1.6 + ASFF + GitLab + JUnit outputs and `convert`, Prowler framework import (105 JSONs, with a licence check on CIS content), Checkov/Trivy golden runs on `lab/terraform` (no cloud needed), read-only MCP server. Launch events (HN, newsletters, CFPs) only after decision 1's exit.
5. **Exploitability truth.** Gate CVE exploitability on KEV/EPSS (no 0.95 for bare `CVECount`); label every path with `validation: verified|inferred|hint`; the toxic-combination floor stays but is documented as an impact policy and shown as such in explanations; opt-in read-only exposure probes attach evidence (Phase 2).
6. **Cuts (explicit).** No further investment in the dashboard beyond maintenance (the cwm look is done; it is not the primary surface); cost/ROI reduced to one card; Python re-implementations removed (Python consumes Go output only); Neo4j/Steampipe sinks kept as exports without investment; JIT brokering, snapshot workload scanning, DSPM sampler, FAIR dollar risk, team/MSP mode (OIDC-lite no earlier than Q2 2027), the 5×5 severity matrix.
7. **Missed-by-all items become tracks:** the scan DB is an attacker's estate map → encryption at rest option + `purge` + raw-JSON secret scrubbing; LLM data-egress statement and outbound-content minimisation; PR-comment topology disclosure + untrusted `terraform show -json` hardening on nimbus's own Action; `verify` flapping on eventual consistency (re-check N times with backoff); Python supply chain (signed wheels, pinned deps); collector scale SLO; operator-role split (read-only vs remediation credentials); rotate the GitHub token mentioned in `.planning/STATE.md` and remove the mention.
8. **Process:** every first-10 list in stage 1 overlapped with in-flight fix tracks; plan v3 converts those into **re-verification** items, not duplicate work. The council's capability map (B) with D's designs and C's correctness specs is assembled into `.planning/IMPLEMENTATION_PLAN_v3.md`; v2 stays as history.
