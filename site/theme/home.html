nimbus

The open-source, unified Cloud Security Posture Manager.

One binary, cloud-posture, pulls Prowler, ScoutSuite, Checkov, Trivy, Steampipe and its own agentless collectors into a single security graph. Then it shows you the attack paths that matter, the one fix that breaks the most of them, the IaC patch (and PR) that applies it, the SQL to prove it, and the audit report to ship.

install

# binary (Linux / macOS / Windows)
curl -fsSL https://raw.githubusercontent.com/DreadpiratePickles/nimbus/main/install.sh | sh
# or from source (Go 1.26)
go install github.com/DreadpiratePickles/nimbus/cmd/cloud-posture@latest
# Python intelligence layer: compliance reports, AI copilot, boto3 checks, FastAPI
pip install -e "python[all]"
# everything, incl. prowler / checkov / trivy / steampipe
docker run --rm -v ~/.aws:/root/.aws -v $PWD:/work ghcr.io/dreadpiratepickles/cloud-posture scan --accounts aws:default

Credentials are never stored: it uses your existing AWS / Azure / GCP / kubectl sessions or environment variables.

attack paths

break the path

nimbus walks the security graph from the internet up to 6 hops toward your crown jewels. Every path gets a published score, likelihood × priority on 0–10. Then it ranks fixes by how many paths they remove, splits them into breaks the path and lowers risk only, and computes the cheapest set of fixes that cuts every path.

prioritisation

risk you can read

Every open finding gets a 1–10 score: severity × context (exposure, identity, data sensitivity, criticality, CVEs, compliance scope, recent change, ownership, attack paths). The reasons come with it. The weights are published in the repo, not hidden.

critical ≥ 9 high ≥ 7 medium ≥ 4 low

remediation

fixes as code

Fixes come as Terraform, CloudFormation, Bicep and Kubernetes templates. --patch rewrites the HCL block in place, validates it, and never widens access. --auto-pr opens a PR with what changed, the paths it closes, risk, rollback and the diff.

query

SQL over your cloud

Findings land in SQLite and come back as zero-ETL views: aws_s3_buckets, attack_path_summary, soc2, graph_nodes… Tables you don't have locally pass through to Steampipe. ask turns plain English into read-only SQL, with an offline fallback.

audit

compliance & evidence

Covers CIS, NIST 800-53, PCI DSS, SOC 2, HIPAA, GDPR, ISO 27001 and custom YAML frameworks. Reports come out as Markdown, JSON, HTML or PDF, plus an evidence ZIP with a SHA-256 manifest per control.

workflow

where you already work

Alerts go to Slack, Teams, PagerDuty, Jira, GitHub Issues, Datadog, Splunk, Sentinel, Elastic, webhooks and syslog, and close on their own once the issue is fixed. It also has a VS Code extension, a pre-commit hook, a GitHub Action, SARIF output and a sticky PR comment.
